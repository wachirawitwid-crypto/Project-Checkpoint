# Power Up! Portfolio 🚀

> เว็บไซต์ Learning Portfolio สำหรับรายวิชา CS100 ที่ช่วยให้นักศึกษาจัดเก็บข้อมูลส่วนตัว ผลงาน และการสะท้อนความคิด (Reflection) ได้อย่างสะดวก รวดเร็ว และครบถ้วนในที่เดียว

---

## 🌟 ฟีเจอร์หลัก (Features)

ระบบถูกออกแบบมาให้ใช้งานง่าย แบ่งเป็น 3 ขั้นตอนหลัก ดังนี้:

1. **กรอกข้อมูลพื้นฐาน (Basic Info):** ระบุชื่อ, Portfolio ID (ตัวเลข 10 หลัก), สิ่งที่ชอบทำ, สิ่งที่เคยลอง และสิ่งที่อยากเรียนรู้เพิ่มเติม
2. **จัดการผลงาน (Projects & Reflections):** เพิ่มผลงานได้ไม่จำกัดจำนวน โดยกรอกรายละเอียด เช่น ชื่อ, ประเภท, วันที่, บทบาท, ทักษะที่ใช้, ลิงก์หลักฐาน และข้อคำถาม Reflection ทั้ง 4 ข้อ พร้อมระบบลบผลงานด้วยไอคอนถังขยะ
3. **หน้าแสดงผลรวม (Showcase):** รวมโปรไฟล์และรายการผลงานทั้งหมดมาแสดงผลในรูปแบบ Portfolio ที่สวยงาม พร้อมปุ่มตรวจสอบลิงก์หลักฐาน

> **💡 Note:** ข้อมูลทั้งหมดจะถูกบันทึกไว้ใน `localStorage` ของเบราว์เซอร์ ข้อมูลจะไม่หายไปเมื่อรีเฟรชหน้าเว็บ และรองรับการใช้งานบนมือถือ (Responsive Design) อย่างเต็มรูปแบบ

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **HTML5 / CSS3 / JavaScript (Vanilla)**
- **Bootstrap 5** (สำหรับการจัดเลย์เอาต์และ UI)
- **Font Awesome & Ionicons** (ไอคอนประกอบ)
